# verlet-rope

rope physics for roblox with verlet integration, no constraints or physics parts.

<img src="progress/03-cloth.gif" width="720" alt="ripping a cloth apart">

`rojo serve` or paste src/Rope.luau into a ModuleScript in ReplicatedStorage and src/Demo.client.luau into a LocalScript in StarterPlayerScripts, then hit play. drag the rope with the mouse, pull hard to snap it, R for a new one.
